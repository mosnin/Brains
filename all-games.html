Working Memory Working Memory Games

Working memory is your mental workspace — the ability to hold and manipulate information in mind while performing tasks. These 8 games target the three sub-systems of Baddeley's working memory model.

Digit Span Backward

Attention Attention Games

Attention encompasses sustained focus, selective filtering, and the ability to divide attention across tasks. These 5 games cover the full spectrum from vigilance to conflict monitoring.

Respond only to target stimuli in a continuous stream. The CPT is widely used to assess sustained attention and impulsivity.

Respond to most stimuli and withhold for a rare target. The Sustained Attention to Response Task measures the capacity for sustained vigilant attention.

Detect rare signal events over an extended period. Trains the ability to maintain alert attention during low-stimulation conditions.

Flanker Task

Identify the center arrow while ignoring flanking distractors pointing in the same or opposite direction. Trains selective attention and conflict monitoring.

Processing Speed Processing Speed Games

Executive Function Executive Function Games

Executive functions are top-down mental processes that regulate thought and behavior. They include inhibition (stopping unwanted responses), cognitive flexibility (switching between rules), and working memory updating. These 7 games target the full executive function triad.

Executive Function 30 Levels

Stroop Color-Word Test

Name the ink color while ignoring the written word. The gold standard test of inhibitory control — suppressing the automatic reading response.

Play Free
Executive Function 30 Levels

Task Switching

Alternate between two different judgment rules for the same stimuli. Directly measures cognitive flexibility and the ability to mentally shift between task sets.

Play Free
Executive Function 30 Levels

Rule Shift Task

Follow one sorting rule, then shift to a different rule without warning. Tests the ability to override established response patterns and update behavioral rules.

Play Free
Executive Function 30 Levels

Trail Making Test

Connect numbered and lettered dots in alternating sequence. Part B of the Trail Making Test is a sensitive measure of cognitive flexibility and set-shifting.

Play Free

Reaction Time Reaction Time Games

Reaction time reflects how quickly the nervous system detects, processes, and responds to stimuli. These games range from simple detection tasks to choice responses requiring rapid decision-making.

Respond to a single stimulus as fast as possible. Measures raw neural processing speed — average adults respond in about 250 milliseconds.

Reaction Time 30 Levels

Respond with different keys to different stimuli. Choice RT requires stimulus identification and response selection — typically 100–150 ms slower than simple RT.

Reaction Time 30 Levels

Solve arithmetic problems as fast as possible. Combines processing speed with working memory, making it a challenging mixed-domain reaction time task.

Reaction Time 30 Levels

Word Recall

Recall and reproduce word lists under timed conditions. Tests verbal memory retrieval speed and the interaction of memory and processing speed.
