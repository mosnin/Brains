Memory Scores by Age: What's Normal at Every Stage

Working memory capacity — your brain's mental scratch pad — follows a predictable developmental arc. It grows rapidly through childhood, peaks in young adulthood, then gradually declines across middle and older age. Here is what the research says is normal at every stage of life.

What Working Memory Scores Measure

Working memory is the cognitive system that temporarily holds and manipulates information while you use it — the number of items you can keep "online" during a task. The two most widely studied metrics are digit span (how many numbers you can repeat in sequence) and Corsi block span (how many spatial locations you can reproduce in order). Together they capture verbal and visuospatial working memory capacity respectively.

The digit span test has been part of standardised cognitive batteries since Wechsler's early work in the 1940s. It remains one of the most reliable single measures of working memory. Average healthy adults can hold approximately 7 ± 2 items (Miller's Law), but this varies meaningfully with age, education, and practice.

Verbal vs. Visuospatial Memory Across the Lifespan

Verbal working memory (measured by digit span) tends to hold up slightly better with age than visuospatial working memory (measured by Corsi block span). This asymmetry has been observed consistently across large normative studies and is thought to reflect the relatively greater resilience of left-hemisphere language networks compared to the right-hemisphere parietal circuits that underpin spatial processing.

Practically, this means older adults often maintain verbal list-learning and word-retrieval capacity reasonably well while noticing greater difficulty with spatial navigation, mental rotation, and remembering where they placed objects — tasks that lean on visuospatial working memory.

In children, the reverse asymmetry is sometimes seen: visuospatial memory develops slightly ahead of verbal memory in early childhood, though both rapidly improve through adolescence.

What Factors Affect Memory Scores

Working memory scores are not fixed. Beyond age, the following factors have robust evidence behind them:

  • Education and cognitive engagement: Higher levels of formal education correlate with larger digit span scores across all age groups, likely reflecting both neural efficiency and practised use of verbal encoding strategies.
  • Cardiovascular health: Hypertension, diabetes, and obesity are each independently associated with lower working memory scores. The mechanisms involve cerebrovascular integrity and prefrontal blood flow.
  • Sleep quality: A single night of sleep deprivation reduces digit span by approximately 0.5–1 item and slows updating speed substantially. Chronic poor sleep has cumulative effects.
  • Stress and anxiety: Elevated cortisol impairs prefrontal function and transiently reduces working memory capacity. Chronic stress has longer-lasting structural effects on the prefrontal cortex.
  • Physical exercise: Aerobic exercise is one of the most replicable memory-protective behaviours. Meta-analyses find that regular moderate exercise improves working memory composite scores by approximately 0.5 standard deviations over 8–12 weeks.
  • Adaptive cognitive training: Tasks that incrementally increase in difficulty — like n-back training — have shown working memory improvements that generalize partially to untrained tasks, especially in children and older adults.
Key Finding: Visuospatial working memory (Corsi span) typically shows age-related decline earlier and more steeply than verbal working memory (digit span). If you notice memory difficulties, it is worth testing both domains separately.

How to Test Your Working Memory

The BrainForge Digit Span test presents sequences of digits and asks you to recall them in order. It automatically adjusts span length based on your accuracy, giving you a precise estimate of your verbal working memory capacity. The Corsi Block Test provides the visuospatial equivalent.

For a more demanding measure of working memory under cognitive load, the Working Memory task requires you to hold and manipulate information simultaneously — closer to how working memory is actually used in daily life.

Frequently Asked Questions

  • Is my memory normal for my age?

    Compare your digit span or working memory score to the age-matched norms in the table above. A digit span of 6–7 items is typical for healthy adults aged 18–50. Scores of 5–6 are normal for adults over 50. If your score is consistently 2 or more digits below the norm for your age group, it may be worth discussing with a healthcare professional, particularly if you notice day-to-day functional changes.

  • Why does memory decline with age?

    Working memory relies heavily on the prefrontal cortex, which shows gradual volume loss from around age 40. Dopaminergic and noradrenergic signalling — which regulate the precision of working memory representations — also become less efficient with age. Additionally, white matter changes slow the speed of information transfer between brain regions that support memory encoding and retrieval. These changes are gradual and do not constitute disease in the absence of more marked functional decline.

  • Can memory be improved with training?

    Yes, particularly working memory. Adaptive training tasks — ones that increase in difficulty as you improve — have been shown in multiple randomised trials to increase digit span and working memory composite scores by 1–2 items over 4–8 weeks of regular practice. Aerobic exercise and sufficient sleep (7–9 hours for most adults) also have robust evidence behind them as memory-protective behaviours that complement direct training.
