Working Memory Visual Memory 30 Levels

Corsi Block Test

Watch a sequence of blocks light up and reproduce the sequence in order. Developed by Philip Corsi in 1972, this is the definitive measure of visuospatial working memory span. The Corsi span (average: 5–6 blocks) is a direct spatial equivalent to digit span, and reveals differences between verbal and spatial memory systems.

Stop Signal Task

Respond to go stimuli as quickly as possible, but stop when an occasional stop signal appears. The stop-signal reaction time (SSRT) is a precise biomarker of response inhibition speed — one of the most studied measures in ADHD, impulse control, and addiction neuroscience.

Visual Pattern Recall

A grid of cells briefly illuminates in a pattern — memorize it and reproduce it. Visual pattern recall tests visual short-term memory encoding, storage, and retrieval. Pattern complexity increases progressively across levels, systematically loading visual working memory.

Choice Reaction Time

Two or more stimuli appear, and each requires a different response. Choice RT extends simple RT by adding stimulus discrimination and response selection — the additional processing takes ~100–150 ms. Hick's Law predicts RT increases logarithmically with the number of choices, and this game lets you measure that directly.

Rule Shift Task

Sort cards or stimuli according to one rule, then — without explicit warning — the rule changes. The Rule Shift Task directly measures the ability to detect rule changes and override established response patterns, a key component of cognitive flexibility and prefrontal executive control.

Trail Making Test

Connect numbered dots in order (Part A), then alternate between numbers and letters (Part B). The Trail Making Test is one of the most widely used measures in neuropsychology. Part B specifically tests cognitive flexibility and the ability to mentally switch between two sequences — sensitive to frontal lobe function and processing speed.

Go/No-Go Task

Respond quickly to Go stimuli and withhold responses to No-Go stimuli. This deceptively simple paradigm is a cornerstone of executive function research. The prepotent response tendency built up by repeated Go trials makes No-Go inhibition genuinely effortful, giving a clean measure of impulse control under time pressure.

Reaction Time 30 Levels

Simple Reaction Time Test

Click or tap the moment a stimulus appears. Simple reaction time is the most fundamental measure in experimental psychology — it has been studied since the 1860s and reflects neural conduction velocity, processing efficiency, and alertness. Your personal best is a meaningful baseline for tracking cognitive health over time.
