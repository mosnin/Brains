Memory Updating Task

Track changing values across multiple mental slots. Each update forces you to discard old information and hold the new value — training the executive core of working memory.

How to Play

The Memory Updating task challenges your ability to continuously refresh information held in working memory.

  1. Study the slots — Each round begins with numbered slots showing initial values (1–9). Memorize them.
  2. Watch the updates — Operations appear one at a time (e.g., "Slot 2 +3"). Mentally calculate and store the new value for that slot.
  3. Enter final values — After all updates, type the current value in each slot. Exact answers required.
  4. Complete 5 rounds per level. Score 80% or higher to advance.

Operations include addition (+), subtraction (-), multiply by 2 (x2), and divide by 2 (÷2, rounded to nearest integer).

What It Measures

Memory Updating directly targets working memory updating, one of three core executive functions identified by Miyake et al. (2000) alongside shifting and inhibition. Updating requires not just holding information but actively replacing outdated representations with current ones — a demanding executive process distinct from simple storage.

Strong updating ability is associated with fluid intelligence, academic achievement, and performance in complex real-world tasks such as following multi-step instructions or managing dynamic situations.

Research

Ecker et al. (2010) developed the memory updating paradigm to isolate the updating component from storage and retrieval demands. Their work showed that updating ability is a distinct, trainable cognitive process. Subsequent training studies (e.g., Dahlin et al., 2008) demonstrated that intensive updating practice produces robust gains in working memory capacity with transfer to fluid intelligence tasks, particularly in younger and older adults. The task activates prefrontal and parietal networks associated with cognitive control.

Frequently Asked Questions

Why does this feel harder than simple memory tasks?

Unlike pure storage tasks, updating forces you to actively overwrite previous values rather than just hold them. This inhibition of old information while encoding new values engages the executive control system, which is more cognitively demanding than passive rehearsal.

What is a good score on the Memory Updating Task?

Consistently clearing levels 1–10 (2–3 slots, basic operations) represents average performance. Levels 11–20 (4–5 slots with multiplication) indicate strong executive working memory. Levels 21–30 (5–7 slots, all operations, faster pacing) reflect exceptional updating capacity found in high-performers on fluid intelligence tests.

Can this task improve fluid intelligence?

Research suggests updating training is one of the more promising routes to far-transfer cognitive gains. Dahlin et al. (2008) found that striatal activity during updating training predicted improvements on an independent intelligence measure. While findings vary across studies, consistent practice with demanding updating tasks is associated with broader cognitive benefits compared to simple memory training.
