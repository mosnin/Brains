Task Switching Test

A classic paradigm measuring cognitive flexibility. A number appears on screen along with a task cue — you must rapidly apply the correct rule (Odd/Even?, Small/Large?, or Greater than 5?) and respond before time runs out. Switching tasks costs time and effort; this game trains you to minimize that "switch cost."

How to Play the Task Switching Test

A single-digit number (1–9) appears in the center of the screen. A colored task cue tells you which rule to apply for that trial:

  • ODD or EVEN? — Press A if the number is odd, B if even.
  • SMALL or LARGE? — Press A if the number is 1–4 (small), B if 5–9 (large).
  • GREATER THAN 5? — (Levels 19+) Press A for Yes, B for No.

Early levels focus on a single task with no switching. From Level 7 onward, the task rule changes unpredictably between trials. A brief cue display window precedes the number — read the rule and prepare your response. The cue window shrinks and switch probability rises as you advance, culminating in near-constant task switching at the hardest levels.

What the Task Switching Test Measures

Task switching is one of the core operations of cognitive flexibility — the ability to reorganize mental resources and shift between different goals or rule sets. Key constructs measured include:

  • Set shifting — disengaging from one task rule and engaging a new one efficiently.
  • Switch cost — the reaction time and accuracy penalty incurred immediately after a task switch, reflecting residual interference from the previous task set ("task-set inertia").
  • Working memory updating — holding the current task rule active in mind while monitoring the cue for potential changes.
  • Proactive interference management — overcoming the pull of the most recently active task rule when it is no longer relevant.

Research Background

The alternating runs paradigm was formalized by Rogers and Monsell (1995), who demonstrated reliable "switch costs" even when participants fully prepared for a task switch during a long inter-trial interval. This "residual switch cost" suggested that voluntary task preparation is incomplete without actual execution of the new task — a key theoretical insight.

Subsequent work by Allport, Styles, and Hsieh (1994) introduced the concept of task-set inertia: the previous task set continues to compete with the current one, slowing performance after switches. Neuroimaging research (Dove et al., 2000; Braver et al., 2003) implicates the dorsolateral prefrontal cortex, anterior cingulate cortex, and parietal cortex in task-switching operations.

Impaired task switching is a hallmark of conditions affecting the prefrontal cortex, including ADHD, schizophrenia, and aging-related cognitive decline. Longitudinal training studies have shown that practiced task switchers show reduced switch costs and more efficient prefrontal engagement over time (Karbach & Kray, 2009).

Frequently Asked Questions

What is "switch cost" and why does it matter?

Switch cost is the performance penalty — in reaction time and/or accuracy — that occurs on a trial immediately following a task change compared to a trial where the same task repeats. It reflects the cognitive effort required to reconfigure mental processing for the new task: inhibiting the old task set, retrieving and applying the new rules, and updating working memory. Minimizing switch cost is important in real-world multitasking situations such as driving while navigating, managing competing work tasks, or switching between subjects in school.

What do the "A" and "B" buttons represent?

The A and B buttons are abstract response labels that are remapped to different meanings depending on the active task rule. For Odd/Even, A=Odd and B=Even. For Small/Large, A=Small and B=Large. For Greater than 5 (Level 19+), A=Yes and B=No. The button labels update each trial to remind you of the current mapping. This remapping is intentional — it adds to the cognitive load by requiring you to flexibly reinterpret the same motor response across different task contexts.

How can I improve my task switching performance?

Consistent practice is the primary driver of improvement. Additionally, research suggests several strategies: (1) Proactive preparation — use the cue display window to actively retrieve and mentally rehearse the upcoming task rule before the number appears; (2) Minimize perseveration — consciously "release" the previous task rule rather than letting it linger; (3) Cross-train with related executive function tasks like the Stroop test and N-Back, which share inhibitory and updating components with task switching; (4) Aerobic exercise has been shown to enhance prefrontal function and reduce task-switching costs (Hillman et al., 2008).
