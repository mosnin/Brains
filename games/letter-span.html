How to Play

The Letter Span task measures how many letters you can hold in short-term memory. Each trial shows a sequence of consonants one at a time on screen. Watch carefully, then use the on-screen keyboard (or your physical keyboard) to type the letters back in the exact order you saw them.

  • Only consonants are used (B, C, D, F, G, H, J, K, L, M, N, P, Q, R, S, T, V, W, X, Z).
  • Each level contains 5 trials. Score 80% or higher to unlock the next level.
  • Sequences grow longer and are displayed faster as levels increase.
  • Both uppercase and lowercase input are accepted.

What It Measures

Letter Span is a classic measure of verbal short-term memory capacity — specifically the phonological loop, one of the core components of Baddeley and Hitch's (1974) multi-component working memory model. The phonological loop stores a limited amount of speech-based information and is linked to language learning, reading, and verbal reasoning.

Average adult forward span is 6–7 items. Scores below 5 may indicate reduced phonological working memory capacity, while consistently recalling 9+ letters suggests exceptional verbal memory.

Research

Baddeley's (2000) updated working memory model identifies the phonological loop as critical for maintaining verbal information through subvocal rehearsal. Letter span tasks are used clinically to screen for dyslexia, ADHD, and language processing disorders (Gathercole et al., 2003). Training phonological working memory has been shown to transfer to improved reading comprehension in children (Dahlin, 2011) and older adults (Borella et al., 2010).

Frequently Asked Questions

Why are only consonants used, not all letters?

Consonants are harder to confuse acoustically than vowels and avoid accidental word formation, which would give some sequences an unfair memory advantage. Using consonants only keeps each trial difficulty consistent and isolates pure phonological span.

What is a good letter span score?

Most adults score between 5 and 7 letters. Reaching level 9–12 (6–7 letters) is average. Levels 13–18 (7–9 letters) indicate above-average verbal memory, and levels 19+ (9+ letters) represent exceptional phonological capacity.

Can I improve my letter span with practice?

Yes. Regular practice with span tasks strengthens the phonological loop and rehearsal strategies. Research suggests 4–6 weeks of consistent training can expand verbal memory capacity and improve related skills like reading and vocabulary retention.
