What Is Visual Pattern Recall?

Visual Pattern Recall is a brain training game that directly targets your visual working memory — the cognitive system responsible for holding and manipulating visual information in mind over short intervals. In each trial, a grid of cells briefly illuminates in a random pattern. The pattern then disappears, and you must reconstruct it from memory by clicking the correct cells. No numbers, no words, no verbal hints — just pure visual and spatial memory.

The game spans 30 progressively harder levels. Early levels present small 3×3 grids with only 3 highlighted cells and generous display times of two full seconds. By the final levels, you are memorizing 16-cell patterns spread across an 8×8 grid with just half a second of exposure — a genuinely demanding challenge that approaches the limits of expert visual working memory capacity.

How to Play

Each trial proceeds in three phases. First, the display phase: a subset of grid cells lights up in teal. Study the pattern carefully and form a mental image of which cells are filled. The pattern is visible for a fixed duration that shrinks as you advance. Second, a brief blank pause of 500 ms clears the grid — this gap prevents a simple afterimage from carrying you through and forces genuine memory encoding. Third, the recall phase: the grid reappears blank and you click cells to reconstruct the pattern. When you have selected the correct number of cells, your answer is automatically evaluated.

After evaluation, color-coded feedback overlays your answer for 1.2 seconds: green cells are correct hits, red cells are false alarms (you clicked them but they were not in the pattern), and orange dashed cells are misses (pattern cells you did not select). This feedback helps you calibrate your mental image and identify systematic errors (e.g., consistently misremembering corner vs. edge positions).

What Does This Game Measure?

Visual Pattern Recall loads heavily on what Robert Logie termed the visual cache — the passive store within Baddeley's visuospatial sketchpad that retains static visual form and pattern information. Unlike the Corsi Block Test, which emphasizes the sequential spatial component (sometimes called the "inner scribe"), Visual Pattern Recall presents all pattern elements simultaneously, stressing the capacity to retain a whole-field snapshot rather than a temporal sequence.

The task also engages iconic memory consolidation — the process by which a brief visual stimulus is encoded from the sensory register into working memory. As display durations shorten across levels, the game increasingly tests how efficiently you can consolidate a visual pattern before it decays. This capacity is distinct from verbal or sequential working memory and is poorly predicted by phonological loop measures like digit span.

Visual Working Memory in Cognitive Neuroscience

The neural basis of visual pattern working memory is primarily right-hemisphere, with key contributions from the occipito-parietal cortex (especially the intraparietal sulcus), the prefrontal cortex (ventrolateral regions for maintenance, dorsolateral for manipulation), and the posterior temporal cortex for pattern recognition. Neuroimaging studies consistently show that holding visual patterns in working memory activates right posterior parietal areas, contrasting with the left-lateralized network typical of phonological storage.

The Wechsler Memory Scale Visual Reproduction subtest measures a related ability — reproducing geometric figures after a brief study period — and has been used clinically for decades to identify visual memory deficits following stroke, traumatic brain injury, and neurodegenerative disease. The grid-based format used here has the advantage of precise, objective scoring (each cell is either correct or incorrect) compared to free-hand drawing tasks.

Research by Logie and colleagues (1995, 2003) demonstrated a clear double dissociation between visual pattern memory and spatial sequence memory, supporting the theoretical partition of the visuospatial sketchpad into a visual cache and an inner scribe. Damage to posterior right-hemisphere regions tends to impair pattern memory disproportionately, while frontal or anterior damage more often disrupts sequential spatial tracking.

Why "No Verbal Shortcuts"?

Many grid-memory paradigms can be partially solved with verbal labeling — for example, encoding highlighted cells as "row 2, columns 1 and 3; row 4, column 2." The random, irregular patterns in Visual Pattern Recall are designed to be difficult to describe verbally, especially at higher grid sizes. The brief display times at advanced levels further prevent deliberate verbal recoding. This means the game truly taxes your visual imagery system rather than simply testing your ability to translate visual information into words and back — making it a more direct window into visuospatial cognitive capacity.

Tips for Better Performance

  • Form a holistic image. Rather than scanning cell by cell, try to perceive the whole pattern as a single gestalt shape — a letter, an arrow, a cluster. Pattern recognition is more efficient than enumeration.
  • Anchor to the grid structure. Use rows and columns as implicit reference frames. Noting "there's a diagonal in the top-right quadrant" is a compact spatial code that uses the grid geometry without full verbal labeling.
  • Use the feedback. After each trial, study which cells you missed and which you falsely selected. Systematic errors reveal biases in your spatial attention and imagery that you can consciously correct.
  • Relax your gaze. Instead of fixating on individual cells, use a soft, distributed gaze that takes in the full grid. This activates peripheral vision and supports holistic encoding.

Frequently Asked Questions

How is this different from the Corsi Block Test?

Both games test visuospatial working memory, but they stress different subcomponents. The Corsi Block Test requires you to recall a temporal sequence of individual locations — it loads on the "inner scribe" (spatial sequence system). Visual Pattern Recall requires you to retain a simultaneous pattern of multiple locations — it loads on the "visual cache" (static pattern storage). The two tasks dissociate neuropsychologically, and many people find themselves significantly better at one than the other. Playing both gives a fuller picture of your visuospatial working memory profile.

Does pattern complexity matter, or just the number of cells?

Both matter. Research shows that visual working memory capacity is sensitive to the number of objects or "chunks" held, but also to the spatial regularity of patterns. Symmetric or structured patterns (like a cross or an L-shape) are easier to retain because they can be encoded as a single gestalt chunk rather than multiple independent locations. The BrainForge implementation uses randomized patterns that deliberately avoid common symmetric forms, keeping the demand on raw capacity rather than pattern recognition shortcuts.

Can this game help with real-world visual memory tasks?

Consistent practice on visual pattern memory tasks has been shown to improve performance on closely related visuospatial tasks (near-transfer), including navigation, visual search, and recognizing briefly glimpsed objects. Transfer to everyday tasks like remembering where you left an object or recalling visual details of a scene is plausible but depends on practice duration and variety. For maximum benefit, combine Visual Pattern Recall with other visuospatial training (Corsi test, spatial n-back) and physical activities that also stress spatial cognition, such as sport or drawing.
